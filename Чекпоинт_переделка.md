## 1. ГЛОБАЛЬНАЯ ЦЕЛЬ И ФУНКЦИОНАЛ
Система для Службы развития ХК «Ак Барс». Несколько тренеров работают со всеми игроками. Привязка к конкретному тренеру НЕ нужна — общая база.

### Целевая структура (Страницы)
1. **Календарь тренера:** Расписание тренировок и игр. Назначение игроков и упражнений.
2. **Игроки:** Список состава (таблица с фото). Разделы: «Звездочки», «Общая группа», «Спецгруппа».
3. **Карточка игрока:** Анкета (возраст авто, школа, команда, характеристика, травмы, загрузка фото в Supabase Storage), редактируемая лепестковая диаграмма навыков (3 линии: Сейчас, План, Итог), индивидуальный календарь.
4. **Отчеты:** Аналитика посещаемости по дням месяца (с выделением травм), тепловая карта навыков, генерация PDF-отчета.
5. **Справочник упражнений:** База упражнений по разделам (редактируемая).
6. **Управление данными:** Импорт/Экспорт Excel, CSV, JSON (в разработке).
